# Viktoria Yani — лендінг школи Таро та відливок

### Технічний опис проєкту для AI-агента (Next.js)

Одна довга сторінка (single page, якорні секції), що презентує 3 курси Вікторії
(Таро, воскові відливки, оловʼяні відливки) і веде відвідувача до заявки або
прямої оплати курсу.

---

## 1. Стек і загальні технічні рішення

- **Next.js** (App Router), рендер сторінки — статичний/SSG, де можливо
- Анімації — **Motion** (колишній Framer Motion): scroll-reveal, hover-стани
  кнопок і карток, плавні transitions між станами (розгортання FAQ/модулів,
  перемикання табів курсів)
- Контент (курси, модулі, відгуки, FAQ) винести в окремі дата-файли
  (наприклад `data/courses.ts`, `data/testimonials.ts`, `data/faq.ts`) —
  компоненти рендерять з масивів, а не хардкодять текст
- Зображення — через `next/image`, з `object-fit: cover`
- Форми — керовані компоненти (controlled inputs), клієнтська валідація перед
  сабмітом
- Адаптивність: mobile-first, брейкпоінти орієнтовно на 541px і 981px
  (як у поточному макеті)
- `prefers-reduced-motion: reduce` — усі анімації мають вимикатись/спрощуватись

## 2. Дизайн-система

### 2.1 Кольори

| Роль                                         | Hex       | Використання                    |
| -------------------------------------------- | --------- | ------------------------------- |
| Фон сторінки (основний, найтемніший)         | `#0B1430` | body background                 |
| Фон секцій (другий рівень)                   | `#131E45` | зебра-фон секцій, картки        |
| Фон карток/елементів (третій рівень)         | `#182554` | інпути, модулі, вкладені картки |
| Найтемніший акцент (шапка мобільного меню)   | `#0E1838` | header, мобільне меню           |
| Основний текст (світлий, теплий)             | `#ECE6D3` | заголовки, основний текст       |
| Другорядний текст (приглушений)              | `#A5AAC4` | описи, підписи                  |
| Плейсхолдери / третинний текст               | `#7B819C` | placeholder в інпутах           |
| Золото — основний акцент, CTA                | `#C9A86A` | кнопки, бордери-акценти, іконки |
| Золото — світліший, для цифр/цін             | `#E8C879` | ціна, цифри кроків              |
| Теракотовий акцент (другорядний)             | `#C08262` | eyebrow-лейбли над заголовками  |
| Рожевий (одиничне використання, помʼякшення) | `#E8998A` | точково, не основний            |

### 2.2 Типографія

- Заголовки: **Playfair Display** (serif), ваги 500/600/700, курсив 500 —
  підключення з Google Fonts
- Основний текст/UI: **Manrope** (sans), ваги 400–800
- Розміри заголовків — через `clamp()`, наприклад h1: `clamp(32px, 5vw, 52px)`,
  h2: `clamp(26px, 3.5vw, 34–36px)`

### 2.3 Форма і простір

- `border-radius`: картки 20–24px, кнопки 20–24px (пігулки), інпути 12px
- Контейнер: `max-width: 1160px`, центрований
- Паддінги секцій: 56px (мобайл) → 72px → 96px (десктоп), горизонтально 20 → 32 → 64px
- Тонкі бордери на золоті з низькою прозорістю: `rgba(201,168,106, 0.15–0.35)`
  для карток і роздільників

### 2.4 Фонові ефекти й анімації (вже закладені в поточному макеті — перенести й підсилити)

- **Star-field**: фіксований (position: fixed) шар із дрібними цятками-зірками
  на світлому кольорі `#ECE6D3`, з `keyframes twinkle` (плавне мерехтіння,
  9s ease-in-out infinite)
- **Reveal-on-scroll**: елементи заходять знизу з fade-in при появі в
  viewport (зараз — clas-based `.reveal`/`.is-visible`, у Next.js варто
  зробити через Motion `whileInView`)
- Легкий hover/tap-фідбек на кнопках і картках курсів

## 3. Структура сторінки (блоки зверху вниз)

### 3.1 Header / навігація

- Лого (текст або знак) зліва
- Десктоп: горизонтальне меню — Про мене · Формат навчання · Курси · Програма ·
  Відгуки · FAQ · Контакти
- Кнопка-CTA праворуч: «Записатись» (веде на форму)
- Мобайл: бургер-меню, що розкриває той самий список вертикально

### 3.2 Hero

- Eyebrow-лейбл: «Онлайн-школа Вікторії»
- H1 (обіцянка результату за конкретний термін)
- Підзаголовок-опис (1 абзац) — методика, соціальний доказ (роки практики,
  кількість учениць)
- 2 кнопки: основна CTA («Обрати курс» → скрол до #courses),
  другорядна («Як проходить навчання» → скрол до #how-it-works)
- Рядок соц-доказу: «N років практики · N+ учениць · онлайн з будь-якої країни»
- Портретне фото Вікторії праворуч (десктоп) / під текстом (мобайл)

### 3.3 Про Вікторію (#about)

- Фото процесу роботи
- Eyebrow + заголовок (позиціонування: «ремесло, а не магія»)
- Абзац тексту про досвід
- Список 2–4 пунктів-переваг (буліти з крапкою-маркером), напр. методика,
  підтримка в спільноті, етика — контент з масиву `aboutPoints`

### 3.4 «Кому підійде навчання»

- Заголовок-питання
- Грід карток (3–4), кожна: іконка/значок, короткий заголовок (2 слова),
  опис-речення — масив `forWhom`

### 3.5 Як проходить навчання (#how-it-works)

- Eyebrow + заголовок
- Ряд кроків (4–5), кожен: номер у колі, заголовок кроку, короткий опис —
  масив `howItWorks`

### 3.6 Курси (#courses) — головний блок, 3 картки

Для кожного з 3 курсів картка містить:

- Обкладинку (16:9)
- Бейдж (опціонально — «хіт», «новий потік» тощо)
- Назву курсу
- Мета-рядок (тривалість + к-сть уроків), напр. «12 тижнів · 24 уроки»
- Короткий опис (2–3 речення)
- Ціну + валюту + приписку про розстрочку
- Кнопку «Дізнатись деталі» → веде або на розгортання деталей, або відкриває
  форму оплати з preset цього курсу (checkout-флоу, див. розділ 5)

Над картками — підзаголовок з датою старту найближчого потоку й приміткою
про обмежену кількість місць.

### 3.7 Програма по модулях (#program)

- Таби — по одному на кожен курс (перемикач активного курсу)
- Під табами — акордеон модулів обраного курсу: заголовок модуля,
  к-сть уроків, розгортання з описом вмісту модуля
- Дані — масив модулів на кожен courseId (`modules[courseId]`)

### 3.8 Відгуки (#testimonials)

- Грід карток відгуків (3+)
- Два варіанти картки: (а) скріншот відгуку (зображення 3:4) або
  (б) текстовий відгук з аватаркою + цитата
- Підпис під кожною: місто · назва курсу

### 3.9 FAQ (#faq)

- Акордеон питань-відповідей (орієнтовно 6–8 пунктів)
- Розгортання одного питання за раз або незалежно — на розсуд агента

### 3.10 Гарантія

- Виділений блок (картка з бордером): умова повернення коштів за перші
  N уроків, без додаткових умов

### 3.11 Форма заявки (#form)

Див. розділ 5.1 — повний опис полів і логіки.

### 3.12 Footer

- Лого + короткий опис школи (1 речення)
- Колонка навігації (дублює якорні посилання)
- Колонка контактів: Telegram / Instagram / Viber / email
- Копірайт-рядок

## 4. Контент-модель (структури даних)

```txt
Course {
  id: string            // "tarot" | "wax" | "tin"
  name: string
  meta: string           // "12 тижнів · 24 уроки"
  desc: string            // короткий опис для картки
  price: number
  currency: string
  installments: boolean   // чи можлива оплата частинами
  image: string
  badge?: string
  modules: Module[]
}

Module {
  title: string
  lessons: number
  detail: string          // текст, що розкривається в акордеоні
}

Testimonial {
  type: "screenshot" | "text"
  image: string
  authorName?: string      // для текстового варіанту
  quote?: string           // для текстового варіанту
  city: string
  courseName: string
}

FaqItem {
  question: string
  answer: string
}

ForWhomCard {
  title: string
  text: string
}

HowItWorksStep {
  number: number
  title: string
  text: string
}
```

## 5. Функціональність

### 5.1 Форма заявки («Залишити заявку»)

Поля:

- Імʼя (текст, обов'язкове)
- Телефон (формат +380, обов'язкове)
- Email (обов'язкове)
- Тип запиту: «Підбір курсу» / «Онлайн-консультація» (перемикач)
- Курс, який цікавить (select, показується тільки якщо тип запиту = підбір
  курсу): опції — 3 курси + «ще не вирішила»
- Месенджер для звʼязку (Telegram / WhatsApp / Viber)
- Чекбокс згоди на обробку персональних даних (обов'язковий, без нього
  кнопка відправки неактивна)

Поведінка: клієнтська валідація обов'язкових полів → успішний стан показує
екран подяки; помилка мережі/сервера → повідомлення про помилку з можливістю
повторити.

### 5.2 Чекаут (оплата курсу)

Коротка форма, що відкривається кліком по кнопці курсу, з уже підставленим
курсом (prefilled/hidden `course`):

- Імʼя, email, телефон — обов'язкові
- Telegram-нікнейм — опційно
- Чекбокс згоди — обов'язковий

Після відправки — редірект на сторінку оплати (провайдер визначається окремо,
не описується тут).

### 5.3 Аналітика (події)

Компоненти мають відправляти events (напр. через `dataLayer.push` або
абстрактний `trackEvent()`, який агент підключить до потрібної системи):

- `lead_submit` — сабміт форми заявки
- `checkout_start` — відкриття форми оплати
- `course_card_click` — клік по картці курсу
- `faq_open` — розгортання питання в FAQ

## 6. Наявні асети (вже є, можна використати)

- Портретне фото Вікторії (hero)
- Фото процесу роботи (about)
- 3 обкладинки курсів (таро / воскові відливки / оловʼяні відливки)
- 3 зображення для відгуків (у т.ч. один скріншот)

## 7. Чого не вистачає для повного наповнення

- Реальні тексти модулів програми для курсів «воскові відливки» і
  «оловʼяні відливки» (для «Таро» є чернетка-орієнтир)
- Реальні відгуки з дозволом на публікацію
- Фінальний список FAQ
- Точні дати старту потоку і кількість місць у групі

---

## 8. Поза межами цього документа

Хостинг, домен, провайдер оплати, email-сервіс і бекенд-платформа —
рішення приймаються окремо і в цей опис не входять.
